## 本轮修复

- 飞书资料选择器从静态演示项改为调用 `/api/v1/feishu/resources`，支持文档、妙记、分页和多选。
- 飞书链接、妙记与粘贴文本导入按用户选择传递 `customer_profile`、`experience` 或 `capability`，不再统一写死经验提取。
- 页面明确展示 AI/飞书真实或模拟模式，并标出演示资料。
- 删除前端写死邀请码；邀请码由服务端校验。
- 邀请验证 Cookie 改为签名、带随机数、十分钟有效、HttpOnly、SameSite Strict，并在 OAuth 启动后消费。
- 增加服务器邀请码启用、轮换、检查和关闭脚本；邀请码只保存在权限 0600 的服务器文件和运行环境中。
- 页面启动时重新读取服务状态，避免 localStorage 显示过期运行模式。
- 合并合作伙伴的非 root 多阶段 Docker、Caddy 和生产 Compose 配置，并强制 `start.sh` 使用 LF，避免 Windows 构建后的 Linux 入口失败。
