# 淘到宝 · 团队作品集导航

这个项目面向企业销售与售前，将资料转化为可审核、可追溯的方案依据。

| 阅读者 | 入口 | 重点 |
|---|---|---|
| 开发招聘方 | [开发作品集](developer.md) | 架构、契约、可信门禁、任务和验证 |
| 产品招聘方 | [产品作品集](product/README.md) | 业务问题、产品取舍、PRD、试点评估 |
| 项目成员 | [贡献与展示指南](contributing.md) | 如何在各自 GitHub 展示真实负责范围 |

产品版可整目录独立发布，所有内部链接均在目录内。
作品集整理不改变业务实现；项目级交付与个人贡献分别呈现。
