## 最值得讨论的三个产品决策

- **历史经验不等于企业能力。** 做过一个项目不能直接推导为现在可以对所有客户承诺同样交付，必须分开审核和引用。
- **快速沟通和复杂研究需要不同流程。** 前者先提供有边界的答复，后者记录阶段、冲突和待专家确认的问题。
- **模型可以给建议，发布权属于业务规则。** 证据失效或缺失时，后端应降级、复核或拦截。
