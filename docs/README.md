## 6. 历史与赛事材料

文件名包含“复赛”“录屏”“录制”“演示准备包”的文档是历史交付材料。它们保留用于需求和决策追溯，但以下内容优先级更高：

1. 冻结及增量 API 契约；
2. 对应版本最终 PRD；
3. 当前代码与数据库迁移；
4. 最新自动化测试和实机验收结果；
5. 历史比赛说明。

发现冲突时先记录并报告，不通过修改冻结契约来迁就历史文档。
