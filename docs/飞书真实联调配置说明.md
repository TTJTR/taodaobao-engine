# 淘到宝引擎飞书真实联调配置说明

## 1. 当前代码能力

- 新版 OAuth 授权码登录、`user_access_token`与`refresh_token`刷新。
- 以用户身份列出和读取其有权访问的飞书文档；飞书妙记可按链接读取信息和文本转写。
- 以用户身份创建研究结果文档。
- 以应用身份获取并缓存`tenant_access_token`，由机器人建群和发送消息。
- 原生飞书事件回调：URL Verification、签名校验、Encrypt Key 解密、群文本消息映射、回复去重和 Deep Research 恢复。

## 2. 飞书开放平台配置

创建“企业自建应用”，启用网页应用和机器人能力。至少申请并发布以下权限：

- `docx:document`：创建、编辑和读取新版文档；
- `space:document:retrieve`：列出用户云空间文件；
- `im:chat:create`：应用身份创建群；
- `im:message`：机器人收发单聊/群聊消息；
- 妙记“导出妙记转写的文字内容”权限（若本次验收妙记）；
- `minutes:minutes.search:read`、`minutes:minutes.basic:read`、`minutes:minutes.transcript:export`：妙记搜索、基本信息与文字导出；
- `offline_access`是 OAuth scope，用于获得 refresh token。

权限名称和 scope 以飞书开放平台当前“权限管理”页面为准。只把已在应用后台开通的用户身份 scope 写入`APP_FEISHU_SCOPES`，否则授权页会返回 20027。

OAuth 重定向 URL 必须与服务端完全一致：

```text
https://你的域名/api/v1/auth/feishu/callback
```

事件订阅请求地址：

```text
https://你的域名/api/v1/expert-collaborations/events/feishu
```

订阅事件`im.message.receive_v1`，并将 Verification Token 与 Encrypt Key 写入服务器环境变量。

## 3. 服务器环境变量

```dotenv
APP_ENV=production
APP_FEISHU_MODE=live
APP_PUBLIC_BASE_URL=https://你的域名
APP_FRONTEND_REDIRECT_URL=https://你的域名/
APP_COOKIE_SECURE=true
APP_FEISHU_APP_ID=cli_xxx
APP_FEISHU_APP_SECRET=仅保存在服务器
APP_FEISHU_VERIFICATION_TOKEN=仅保存在服务器
APP_FEISHU_ENCRYPT_KEY=仅保存在服务器
APP_FEISHU_TOKEN_ENCRYPTION_KEY=Fernet随机密钥，仅保存在服务器
APP_FEISHU_SCOPES=offline_access docx:document space:document:retrieve minutes:minutes.search:read minutes:minutes.basic:read minutes:minutes.transcript:export
```

不要把 App Secret、Verification Token、Encrypt Key 或用户 Token 提交到 Git。修改环境变量后重建/重启应用容器。

生成 Token 数据库加密密钥：

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

该密钥必须长期保存且不能随意更换；丢失后数据库内的飞书用户 Token 无法解密，只能要求用户重新授权。

## 4. 联调顺序

1. 打开`/api/v1/auth/feishu/start`，访问响应中的授权地址。
2. 授权返回后验证`/api/v1/me`。
3. 验证`/api/v1/feishu/resources?type=document`并导入一篇真实文档。
4. 创建 Deep Research，选择真实贡献者，确认专家协作。
5. 检查飞书研究文档、协作群和机器人消息。
6. 专家回复时带问题编号（多问题场景例如`EXP-Q1：...`），验证任务从`waiting_expert`恢复为`researching`。

## 5. 当前部署前风险

- 新写入和刷新后的用户 Token 使用 Fernet 加密存储；Live 模式缺少加密密钥时服务拒绝启用飞书适配器。历史明文 Token 会保持兼容，用户重新授权或刷新后自动转为密文。
- 当前阿里云只有公网 IP 和 HTTP。是否能保存为飞书 OAuth/事件回调地址取决于开放平台校验；稳定演示应绑定域名并启用 HTTPS。
- 飞书应用权限新增后必须发布新版本，并让测试成员处于应用可用范围内。
