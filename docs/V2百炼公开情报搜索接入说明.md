# V2 百炼公开情报搜索接入说明

## 1. 交付结论

V2 情报模块新增阿里云百炼真实公开搜索入口，替代“必须依赖 Open Enrich/付费大数据供应商才能自动发现来源”的单点依赖。Open Enrich 保留为可选扩展，不再是自动搜索的唯一方案。

本能力不新增第六个 `AIEngine` 方法，不修改根目录冻结 `openapi.yaml`，也不修改 `app/contracts/ai.py` 的五个方法签名。新增接口只记录在 `docs/openapi-v2-incremental.yaml`。

## 2. 真实数据流

```text
员工输入检索主题
  -> POST /api/v1/intelligence/search-runs/automatic
  -> 持久化 intelligence_search Worker
  -> 百炼 Web Search（只发现 URL）
  -> 公网 URL / DNS / SSRF 校验
  -> 受限正文抓取与正文哈希
  -> RawArtifact 不可变快照
  -> 待审核 IntelligenceItem
  -> IntelligenceSnapshot
  -> 可选 extract_profile 画像抽取
  -> Profile Proposal
  -> 员工确认后才写入 external_intelligence
```

## 3. 可信边界

- 百炼返回的搜索摘要不直接作为客户事实、企业能力或历史经验。
- 只有能够安全抓取到公开正文的 URL 才能进入 RawArtifact 和后续抽取。
- 无法抓取、登录受限、验证码拦截或非公网地址会被记录为 skipped，不会生成 Mock 内容。
- 自动画像抽取继续复用冻结的 `extract_profile`；画像 Proposal 必须人工确认。
- 外部情报继续写入 `external_intelligence` 命名空间，不能伪装为企业内部已确认事实。
- 每次运行保留 provider request ID、来源顺序、正文哈希、抓取时间和独立情报快照。

## 4. 新增接口

`POST /api/v1/intelligence/search-runs/automatic`

请求示例：

```json
{
  "query": "某制造集团近期数字化项目与招聘信号",
  "purpose": "customer_profile",
  "profile_id": "00000000-0000-4000-8000-000000000001",
  "max_results": 5,
  "language": "zh-CN",
  "country": "CN"
}
```

写请求必须携带 `Idempotency-Key`。接口返回 SearchRun 与 WorkflowTask，浏览器通过现有搜索任务与运行记录接口查看阶段和结果。

## 5. 配置

默认复用部署环境中的 `DASHSCOPE_API_KEY`。如果公开搜索需要独立密钥，可设置：

```dotenv
APP_BAILIAN_SEARCH_API_KEY=
APP_BAILIAN_SEARCH_MODEL=qwen-plus
APP_BAILIAN_SEARCH_STRATEGY=turbo
APP_BAILIAN_SEARCH_TIMEOUT_SECONDS=45
APP_BAILIAN_SEARCH_MAX_RESULTS=8
```

也可在工作区“API 路由控制台”中配置 `web-search` 能力。密钥沿用现有服务端加密存储，不回显给浏览器；保存前会发起一次真实百炼搜索验证。

## 6. 失败与降级

- 未配置密钥：任务失败并返回 `PROVIDER_UNAVAILABLE`，不使用 Mock。
- 百炼超时或临时失败：持久 Worker 在截止时间和最大尝试次数内重试。
- 部分来源抓取失败：运行状态为 `partial`，成功来源仍保留快照。
- 所有来源均无法抓取：运行失败并返回 `SOURCE_TEMPORARILY_UNAVAILABLE`。
- 员工仍可使用原有手工来源入口，粘贴真实公开 URL 与原文完成同一可信治理链路。
