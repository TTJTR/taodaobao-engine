## 2. 未通过项

### BUG-IHTML-001：生成结果突破事实边界

- 严重程度：S1
- 状态：待修复
- 输入事实：`某制造客户试点中，设备故障资料检索从人工询问改为统一检索。`
- 实际输出：在“证据与依据”中生成 `效率显著改善`，并将其标记为“历史事实”。
- 问题：输入没有提供效率改善结论或量化证据，模型进行了未经支持的增强，违反“所有企业事实只能来自用户材料”的核心规则。
- 另一个风险样例：生成 `选择 1-2 个工厂` 的实施建议，但未稳定标记为 AI 建议或待确认。
- 关闭条件：生成前必须接收结构化 FactLedger/FactBinding；生成后执行逐项证据校验。Prompt 只能作为第一层约束，不能替代 EvidenceGuard。

### BUG-IHTML-002：最后章节导航高亮错误

- 严重程度：S3
- 状态：待修复
- 复现：点击“风险与待确认”。
- 实际结果：页面已经滚动到“风险与待确认”，但 `aria-current=true` 仍停留在“实施路径”。
- 根因方向：点击后的定时高亮与 IntersectionObserver 互相覆盖，最后一章受页面底部可滚动空间影响，无法满足当前 observer 判定区间。
- 关闭条件：任一导航项点击后，页面位置、视觉高亮和 `aria-current` 必须一致；首章、中间章、末章分别回归。

### BUG-IHTML-003：安全审计规则不完整

- 严重程度：S2
- 状态：待修复
- 当前已拦截：`fetch`、XHR、WebSocket、EventSource、`eval`、`new Function`、浏览器存储、父页面访问、显式 HTTP(S) `src/href`、部分跳转 API。
- 当前未覆盖或覆盖不足：CSS `url()`/`@import`、相对路径资源、`form` 提交、`iframe/object/embed`、`javascript:` URL、meta refresh、`document.location`、动态创建资源节点等。
- 风险：系统 Prompt 声明“禁止”不等于运行时门禁；模型输出或恶意输入可能绕过正则审计。
- 关闭条件：使用白名单 HTML/CSS/JS 策略或标准 Sanitizer；增加 CSP；针对所有禁止能力建立负向测试。

### GAP-IHTML-001：尚未接入淘到宝可信数据链

- 严重程度：S1（集成阻断）
- 状态：未实现
- 当前输入：用户在 textarea 中粘贴自由文本。
- 缺少：`research_task_id`、客户画像版本、RetrievalSnapshot、SourceSnapshot、FactLedger、FactBinding、EvidenceGuard、Trust Gate 决策和输出资产版本。
- 影响：虽然项目可生成好看的页面，但无法证明页面使用的是当前 V2 已审核事实，也无法与快速方案、Deep Research、情报、招标或演练成果稳定联动。
- 接入建议：把本项目定位为 Renderer/Generator Sidecar；主后端传入受控 `PresentationInputSnapshot`，生成器只负责叙事规划和渲染，不拥有事实选择权。

### GAP-IHTML-002：缺少可合并工程基线

- 严重程度：S2
- 状态：未实现
- 当前目录不是 Git 工作树，没有分支、提交记录、自动化测试、依赖锁文件和正式增量契约。
- 影响：无法安全区分开发改动，不能直接并入 `v2` 基线。
- 关闭条件：建立独立功能分支；补单元测试和浏览器测试；定义 V2 增量接口；提交交接说明与回滚方式。

### RISK-IHTML-001：云端暴露时缺少服务级鉴权与限流

- 严重程度：S2
- 当前默认只监听 `127.0.0.1`，本地原型风险可控。
- 若部署到云端：`POST /api/generate` 必须位于登录、工作区权限、幂等、限流、用量审计和超时控制之后，不能直接公网开放，否则会造成模型费用和数据泄露风险。

## 3. 视觉与体验观察

- 桌面首页视觉完成度较高，信息层级清晰，没有明显横向溢出。
- 生成页面整体为暖白、蓝灰商业风格，未出现深色科技大屏或大量 emoji。
- 390×844 下页面可使用，但顶栏品牌、实验标签、模型和“安全沙箱”信息拥挤并发生多行换行；属于视觉优化项，不阻断原型测试。
- 移动预览模式只是缩窄内部 iframe，左侧材料编辑区仍保持桌面布局；它适合在电脑上检查生成内容，不等于完整移动端产品交互。

## 4. 验收结论

### 独立原型

**有条件通过。** 输入材料、调用 DeepSeek、生成完整单文件 HTML、沙箱预览、源码查看、移动宽度预览和下载链路具备可演示基础。

### 淘到宝 V2 正式功能

**不通过。** 当前最主要阻断不是视觉，而是事实选择仍由自由文本和 Prompt 控制，已经出现未经证据支持的“历史事实”。在接入 FactLedger/EvidenceGuard 和后端 Trust Gate 前，不应把该项目描述为“可信方案生成正式链路”。
