# 淘到宝引擎产品需求索引

本目录只保存产品需求、业务规则和必要的历史版本。团队分工、赛事材料、录屏脚本、接力提示词和 Git 协作说明不属于 PRD，已从公开作品集版本移除。

## 当前产品基线

- [淘到宝引擎本地版产品 PRD](淘到宝引擎_本地版产品PRD.md)：当前产品定位、用户、业务模块、可信规则、本地部署、验收和版本路线。
- [企业级能力边界与升级路线](../企业级能力边界与升级路线.md)：当前能做、不能做以及正式商用前必须完成的升级。

阅读产品时优先使用以上两份文档。实现与文档发生差异时，以仓库根目录 `openapi.yaml`、`app/contracts/ai.py`、数据库迁移和自动化测试为事实依据。

## 版本目录

- `v0.5/`：早期 MVP 范围、服务端 PRD、需求倒推与本地交互原型。
- `v1/`：V1 总需求、后端模块 PRD、AI 服务模块 PRD、外部展示说明与本地交互原型。
- `v2/`：情报与招标、方案演练、真实运行约束及 V2 文档索引。

## 冻结与增量契约

- HTTP 冻结契约：仓库根目录 `openapi.yaml`。
- 后端与 AI 冻结契约：`app/contracts/ai.py`，仅包含五个既定方法。
- V1/V1.1 增量契约：`docs/openapi-v1-incremental.yaml` 与 `docs/openapi-presentation-v1.1-incremental.yaml`。

历史需求目录中的接口说明用于需求追溯，不覆盖仓库中的冻结与增量契约。
