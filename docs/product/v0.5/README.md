# 淘到宝引擎MVP方案

## 文件夹目的

本文件夹保存早期 MVP 的产品范围、交互原型与服务端需求，用于解释产品如何从快速检索逐步演进到完整售前工作台。当前产品能力以产品目录中的本地版主 PRD 为准。

## 当前决策

1.可复用的不只是用户画像，还包括客户会话、内容来源、经验资产、原子能力、检索、引用和飞书身份。
2.完整产品抽象为10项一级能力；有数据的MVP只实现前6项。
3.有真实企业资料时，优先完成经验沉淀、PRD 原子能力拆分和快速检索。
4.没有真实企业资料时，只允许使用明确标记的示例数据验证流程，不能用 Mock 结果冒充真实功能。
5.Multi-Agent是Deep Research的技术实现，不是一级产品功能，也不进入首个MVP。
6.前端、后端与 AI 编排共用冻结契约，历史文档不得覆盖当前 HTTP 路径和字段语义。

## MVP黄金路径

```text
登录
→创建客户方案会话
→输入或导入客户背景
→生成并确认共享用户画像
→检索企业经验与原子能力
→输出答案、来源、限制和建议追问
→后续提问继续复用同一画像和资产服务
```
