第一类是前端和后端之间的 HTTP 接口，发：

第二类是后端和 AI Harness 之间的内部接口，发：

- [AI 调用契约](D:/神州/app/contracts/ai.py)

各部分作用：

- `app/contracts/ai.py`：你和 Molly 的唯一内部调用边界
- `app/core/`：配置、错误码、Request ID、异常处理、幂等基础
- `app/db/database.py`：统一数据库连接和事务
- `app/db/models.py`：资料、画像、资产、会话和快照的数据基线
- `openapi.yaml`：前后端唯一 HTTP 契约
- `pyproject.toml`：统一 Python 和依赖版本
- 两份文档：架构约束、操作记录和验收依据
