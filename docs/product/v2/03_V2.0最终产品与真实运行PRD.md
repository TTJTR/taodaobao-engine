# V2.0 最终产品与真实运行 PRD

本文件是需求目录中的最终入口。完整冻结内容由主仓库
`docs/V2.0最终产品与真实运行PRD.md` 维护，合并或发版时两份文件必须同步。

## 最终主线

- 磋商前：公开情报、客户画像建议、招标拆解与响应矩阵；
- 磋商中：快速方案、方案演练、互动 HTML；
- 磋商后：Deep Research、专家协作、事实审计与经验沉淀；
- 可信底座：资料、经验、原子能力、来源快照、权限和审核状态。

## 真实性冻结规则

1. 生产业务接口、Worker 和前端不得使用 Mock 结果；依赖缺失时必须跳过、失败或显示未配置。
2. 仅允许隔离的内置虚构文档验证真实索引；必须标记为演示资料，不能进入正式客户输出。
3. 公开情报只能生成画像 Proposal，员工确认后才可写入长期画像。
4. 经验与能力分库、分审、分检索；每次方案保留独立证据快照。
5. V2.0 展示交付以互动 HTML 为正式目标，不以 PPTX 为验收承诺。

## 冻结依赖

- 根目录 `openapi.yaml` 与 `app/contracts/ai.py` 五方法签名不可破坏；
- V1/V1.1/V2 接口只通过增量契约追加；
- PostgreSQL + pgvector、百炼 Chat/Embedding、飞书、DeepSeek HTML 均使用真实 Provider；Open Enrich 为默认关闭的可选补充 Provider。任何 Provider 未配置时均不得回退 Mock。

## 验收入口

- 全量测试、Ruff、compileall、Alembic；
- `scripts/verify_builtin_document_index.py`；
- 飞书 OAuth、资料同步与真实建群在线冒烟；
- 互动 HTML FactBinding 与安全审计；
- 业务前端空工作区不得出现固定客户、方案或经营指标。
