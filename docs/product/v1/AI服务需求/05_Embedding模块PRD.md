# Embedding模块PRD

## 1.模块信息

- 编号：AI-05
- 目标版本：V0.5核心。
- 目标：统一经验、能力和查询的向量模型与文本构造，使后端可稳定入库和检索。

## 2.边界说明

`ai.py`没有Embedding方法且接口已冻结，因此本模块不是新增跨服务接口，而是AI代码库中的共享`EmbeddingProvider`/库。后端向量模块通过同一依赖包或同进程适配器调用；不得擅自给`AIEngine`加第六个方法。

## 3.依赖

|方向|模块|依赖内容|
|---|---|---|
|上游|经验/能力提取|结构化字段|
|上游|检索意图|query_text、约束和标签|
|上游|模型适配|厂商、密钥、超时|
|下游|后端向量检索|向量、embedding_version、内容指纹|

## 4.文本构造

- 经验：名称+适用问题+主要方案+前置条件+适用条件+风险+标签。
- 能力：名称+描述+输入+输出+前置+限制+标签。
- 查询：客户问题+明确目标+硬约束+行业/场景；不拼入无关画像字段。

经验和能力使用同一向量维度，但必须带asset_type并分开召回。

## 5.功能要求

|编号|要求|验收|
|---|---|---|
|AI05-01|批量和单条Embedding结果维度一致|入库无维度错误|
|AI05-02|文本构造确定性且可测试|相同结构得到相同内容指纹|
|AI05-03|返回embedding_version|换模型可批量重建|
|AI05-04|空文本和超长文本明确处理|不生成无意义向量|
|AI05-05|中文业务短文本有基本相似度回归集|黄金查询命中预期资产|

## 6.异常与降级

Embedding失败不影响资产保存，但资产保持“未向量化/不可检索”。模型切换必须新建版本，不混用不同维度向量。

## 7.交接边界

本模块只负责语义表示，不决定审核资格、TopK和最终方案。
