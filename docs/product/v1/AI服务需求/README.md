# 淘到宝引擎AI服务模块PRD索引

## 使用方式

本目录按可独立开发的AI能力拆分PRD。AI服务只通过`../../后端_开发/ai.py`与后端交互，不直接写业务数据库，也不自行决定资产是否通过审核。

## 冻结边界

当前唯一五个方法：

```text
extract_profile
extract_experience
extract_capabilities
extract_search_intent
generate_solution
```

不得新增第六个跨服务方法。Embedding作为AI服务内可复用适配库并由后端检索模块调用统一实现；V1的Deep Research通过版本化context和增量Schema扩展，不改变方法签名。

## 接手原则

产品或转入AI服务的开发可以安全承接：测试样本、Prompt用例、Schema校验、引用核验、评测脚本、飞书模板和单个节点优化。模型适配器、向量版本和生产密钥由一人统一维护。
