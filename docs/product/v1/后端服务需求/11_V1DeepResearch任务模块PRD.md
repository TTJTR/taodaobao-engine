# V1 Deep Research任务模块PRD

## 1.模块信息

- 编号：BE-11
- 目标版本：V1正式能力。
- 目标：把复杂问题作为可恢复长任务执行，复用V0.5画像和知识资产，产出有证据的研究报告。

## 2.范围

包含任务创建、阶段状态、进度、取消、重试、断点、研究快照、专家等待、研究任务选择数据和报告持久化。不包含各AI节点内部Prompt。

## 3.依赖

|方向|模块|依赖内容|
|---|---|---|
|上游|客户画像|同一确认画像|
|上游|向量检索|经验/能力召回和快照|
|上游|AI运行编排|V1深度工作流调用|
|下游|专家识别与反馈|明确的知识缺口和专家问题|
|下游|专家协作执行|研究报告、候选专家和待确认项|

## 4.契约策略

`CreateTurnRequest.mode`当前固定为`quick`，不能修改其行为。V1新增独立Deep Research任务路由和Schema，以及供专家协作使用的任务列表/上下文读取能力；内部仍通过`generate_solution(context, retrieval_snapshot)`，在`context`中提供版本化`mode=deep`和阶段信息，不改Python方法签名。

## 5.状态机

```text
queued→planning→researching→synthesizing→completed
                       ├→waiting_expert→researching
                       ├→failed→retry
                       └→cancelled
```

## 6.功能要求

|编号|要求|验收|
|---|---|---|
|BE11-01|用户明确选择Deep Research后才创建任务|快速方案不会自动升级|
|BE11-02|任务记录客户、会话、问题、完成条件|刷新后可恢复|
|BE11-03|每个阶段保存进度摘要和中间快照|前端可展示真实阶段|
|BE11-04|可暂停等待专家回复并继续|等待不占用模型调用|
|BE11-05|冲突证据进入待确认|系统不私自选一个事实|
|BE11-06|报告保存结论、证据、路线比较、限制、待确认、专家问题|来源可点击追溯|
|BE11-07|取消后停止新步骤但保留已完成记录|用户能看见取消原因|
|BE11-08|研究页提供“一键发起专家协作”|自动携带任务、对话、文档、画像、快照和缺口|
|BE11-09|专家协作页可按权限选择研究任务|只返回当前workspace可访问任务|
|BE11-10|研究任务输出统一专家协作上下文包|两个入口读取结果一致|
|BE11-11|接收专家回复后从waiting_expert恢复researching|不重跑已完成阶段|

## 7.异常与降级

- 单阶段失败允许按幂等步骤重试，不从头重复已完成外部动作。
- 专家未回复可由用户选择“带缺口继续完成”。
- 同一任务已有进行中专家协作时，一键发起直接打开原协作。
- 证据不足时仍输出研究过程和缺口，不伪造完整报告。

## 8.交接边界

本模块负责长任务状态、研究上下文包和双向状态，不负责飞书建群、专家算法和Prompt。接手人可专注任务队列与状态机。
