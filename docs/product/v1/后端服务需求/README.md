# 淘到宝引擎后端模块PRD索引

## 使用方式

本目录把 V0.5 至 V1 后端拆成边界清晰的服务模块。每份 PRD 写明上游、下游、冻结契约、状态、异常和验收，可用于理解系统设计或独立实现对应模块。

## 冻结边界

- HTTP 契约：仓库根目录 `openapi.yaml`。
- 后端与 AI 契约：仓库根目录 `app/contracts/ai.py`。
- 禁止修改V0.5既有路径和五个AI方法签名；V1新增能力另做增量契约。

## 实现原则

接口冻结后允许替换模块内部实现，但必须保证契约与状态规则不变、验收用例通过，并完成上下游联调。
