# 淘到宝引擎后端模块PRD索引

## 使用方式

本目录把V0.5至V1后端拆成可独立认领的服务模块。每份PRD都写明上游、下游、冻结契约、状态、异常和验收。三人团队不需要复杂流转：认领模块前读总PRD和本模块PRD，完成后用其中验收用例联调即可。

## 冻结边界

- 前端与后端：`../../后端_开发/openapi.yaml`。
- 后端与AI服务：`../../后端_开发/ai.py`。
- 实际文件名为`ai.py`，当前不存在`api.py`。
- 禁止修改V0.5既有路径和五个AI方法签名；V1新增能力另做增量契约。

## 接手原则

接口冻结后，模块可以换人承接。接手人只需保证：契约不变、状态规则不变、验收用例通过、上下游至少联调一次。产品也可承接测试数据、状态规则、验收脚本和低风险AI辅助模块。
