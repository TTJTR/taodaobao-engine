# API联调与部署模块PRD

## 1.模块信息

- 编号：BE-09
- 目标版本：V0.5联调，V1公开演示。
- 目标：让前端逐页替换本地Mock，并在大陆网络可访问环境稳定运行。

## 2.依赖

|方向|模块|依赖内容|
|---|---|---|
|上游|全部后端模块|可运行API和迁移|
|上游|前端|基于OpenAPI的调用层|
|下游|评委/测试者|公开URL和可重置演示空间|

## 3.冻结契约

- 自动校验`后端_开发/openapi.yaml`。
- `GET /health`返回service、database、ai、ai_mode。
- V1新增路由必须在独立增量版本中记录，不覆盖V0.5示例。

## 4.功能要求

|编号|要求|验收|
|---|---|---|
|BE09-01|按OpenAPI生成或维护前端客户端|请求/响应无手写字段漂移|
|BE09-02|为全部路由建立契约烟测|部署后自动执行|
|BE09-03|提供Docker Compose和`.env.example`|空环境按说明可启动|
|BE09-04|数据库迁移可重复执行|全新库和已有库均成功|
|BE09-05|部署到大陆可直接访问的HTTPS环境|评委无需翻墙|
|BE09-06|日志按request_id串联|一次失败能定位到模块|
|BE09-07|一键初始化/重置模拟数据|演示前恢复黄金案例|
|BE09-08|依赖失败有降级开关和明显标识|不会把Mock伪装成真实结果|
|BE09-09|前端正式入口不得调用不存在的服务|V1三项能力全部有真实状态|

## 5.推荐部署

- 前后端：国内轻量云服务器或云托管容器，Nginx/Caddy统一HTTPS入口。
- 数据库：同地域PostgreSQL+pgvector，比赛期可单机容器并每日备份。
- 文件：尽量不落本地文件，只存正文和飞书来源ID；必要附件使用国内对象存储。
- AI密钥：仅服务端环境变量保存。

## 6.交接边界

部署模块不改变业务规则。任何为部署便利而修改契约的行为，必须先更新增量契约和测试。
