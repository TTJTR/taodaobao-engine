# 飞书接入模块PRD

## 1.模块信息

- 编号：BE-02
- 目标版本：V1正式能力。
- 目标：把用户主动选择且有权限的飞书文档、妙记和协作动作转换为内部统一输入输出。

## 2.范围

包含OAuth凭证托管、文档选择、链接解析、正文/作者/原文修改时间读取、妙记读取、权限复查、结果文档、机器人和群聊的底层适配。不负责AI提取和业务审核。

## 3.依赖

|方向|模块|依赖内容|
|---|---|---|
|上游|身份与权限|用户、租户、授权token|
|上游|飞书开放平台|文档、妙记、云空间、消息与群API|
|下游|资料与任务|标准化正文和来源元数据|
|下游|专家协作|用户信息、建群、发消息、建文档|

## 4.冻结契约

- V0.5入口使用`POST /sources/import-link`，不可破坏。
- `Source`必须写入`source_url`、`author`、`source_updated_at`、`synced_at`。
- 文档选择器、妙记列表和V1协作动作若需HTTP路由，作为V1增量契约新增。
- 不修改`ai.py`。

## 5.功能要求

|编号|要求|验收|
|---|---|---|
|BE02-01|从链接识别资源类型和token|支持正式飞书文档链接；非法链接明确拒绝|
|BE02-02|读取正文、标题、作者、原文修改时间|资料详情字段与原文一致|
|BE02-03|文档选择器只列用户有权限的条目|越权文档不展示也不可导入|
|BE02-04|妙记可主动选择并读取转写|不可读取时提示粘贴转写文本|
|BE02-05|再次同步比较`source_updated_at`|原文变化触发资产`source_updated`|
|BE02-06|权限失效时停止后续召回|历史快照仍可展示“当前不可访问”|
|BE02-07|所有外部调用设置超时、重试和request_id|限流后不重复创建资源|

## 6.状态与异常

- 来源可用：正文读取成功且权限仍有效。
- 原文更新：保留旧内容版本，触发重提取/重审核，不覆盖历史快照。
- 已删除/无权限：退出检索，前端显示原因。
- 飞书限流：指数退避；创建文档、群和发消息使用幂等键。

## 7.交接边界

本模块输出统一`Source`元数据或明确飞书错误。接手人只需熟悉飞书API和权限，不负责Prompt、向量或方案生成。
