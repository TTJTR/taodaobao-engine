# 资料与任务模块PRD

## 1.模块信息

- 编号：BE-03
- 目标版本：V0.5核心，V1增强真实同步。
- 目标：把链接或文本变成可追踪的资料，驱动解析、AI提取和人工审核。

## 2.范围

包含导入、资料列表/详情/更新、业务用途、异步任务、处理状态、重试、删除标记和AI标签。不包含具体画像/经验/能力字段生成。

## 3.依赖

|方向|模块|依赖内容|
|---|---|---|
|上游|身份与权限|workspace和操作者|
|上游|飞书接入/前端|正文、链接、作者和时间|
|下游|AI运行编排|raw_text、source_id、purpose|
|下游|画像/可信资产|提取草稿和来源关系|
|下游|检索|来源可用性门禁|

## 4.冻结契约

- `/sources/import-link`、`/sources/import-text`
- `/sources`、`/sources/{source_id}`
- `/sources/{source_id}/refresh`、`/sources/{source_id}/retry`
- `/jobs/{job_id}`
- 使用`SourcePurpose`、`SourceStatus`、`JobStatus`原枚举。

## 5.状态机

```text
pending→fetching→parsing→extracting→pending_review→completed
    └──────────────────────────────→failed→retry
```

任务状态使用`pending→running→completed/failed`。资料状态与任务状态分开保存。

## 6.功能要求

|编号|要求|验收|
|---|---|---|
|BE03-01|导入时必须指定画像/经验/能力用途|错误用途被契约拒绝|
|BE03-02|相同workspace、来源URL和内容版本保持幂等|重复点击不产生重复资产|
|BE03-03|资料列表支持状态、用途和分页筛选|数量与详情一致|
|BE03-04|异步任务逐阶段更新并可轮询|前端能显示真实进度|
|BE03-05|AI标签作为草稿保存并允许人工修改|修改不改原文内容|
|BE03-06|失败记录错误码、摘要和是否可重试|重试不会重复旧成功步骤|
|BE03-07|原文变化触发关联资产失效|旧资产退出检索|

## 7.异常与降级

- 空正文、超长文本、非法链接：导入前拒绝。
- 文档读取失败：资料进入`failed`，保留重试入口。
- 模型失败：资料保留，任务失败，不生成半成品已校验资产。

## 8.交接边界

本模块完成到“原始资料和任务状态可靠”。具体提取质量由AI模块承担，审核和可用性由可信资产模块承担。
