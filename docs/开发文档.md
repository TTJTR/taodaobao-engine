## 3. 当前产品范围

V0.5 目标是跑通以下黄金流程：

```text
飞书登录或 Mock 登录
  -> 导入飞书文档或粘贴文本
  -> 提取客户画像、经验或原子能力草稿
  -> 人工修改和审核
  -> 创建客户会话并输入需求
  -> AI 提取结构化检索意图
  -> 数据库过滤、排序并形成 Top-K 检索快照
  -> AI 基于快照生成八区块方案
  -> 引用和事实边界校验
  -> 保存结果并支持多轮追问
```

当前阶段不实现向量数据库、Multi-Agent、Deep Research、知识图谱、自动建群、PPT 生成和复杂微服务基础设施。

### 4.1 Dev A

### 4.2 Molly

- AI 结构化 Schema。
- 客户画像、经验和能力提取算子。
- `SearchIntent` 提取算子。
- 方案生成 Prompt 与生成算子。
- 引用、边界和防编造质检逻辑。

### 4.3 AI 与服务端边界

- AI 不接收全量经验或能力列表。
- AI 通过 `extract_search_intent(context)` 返回结构化检索意图。
- Dev A 在数据库层完成工作空间隔离、状态过滤、硬约束过滤、排序和 Top-K 截断。
- Dev A 只向 `generate_solution` 传入最多 3 条经验和 5 条能力的固化快照。
- Molly 的算子遇到 LLM 错误时直接抛出 Python Exception。
- Dev A 在 AI Harness 捕获异常，执行重试、错误码转换和任务状态落库。

## 6. 已实现基础能力

### 6.1 FastAPI 应用入口

- 根目录 `main.py` 导出 ASGI `app` 和应用工厂 `create_app`。
- `app/main.py` 创建 FastAPI 应用、注册中间件、异常处理器和 V1 路由。
- 本地启动入口为 `uvicorn main:app --reload`。

### 6.2 统一响应

成功响应：

```json
{
  "request_id": "req_xxx",
  "data": {}
}
```

失败响应：

```json
{
  "request_id": "req_xxx",
  "error": {
    "code": "INTERNAL_ERROR",
    "message": "服务暂时不可用",
    "retryable": true,
    "details": {}
  }
}
```

### 6.3 Request ID

- 优先透传请求 Header 中的 `X-Request-ID`。
- 请求未提供时生成 `req_<uuid>`。
- 响应体和 `X-Request-ID` 响应 Header 使用同一个值。

### 6.4 全局异常处理

- `AppError`：保留业务错误码、HTTP 状态、是否可重试和详情。
- `RequestValidationError`：转换为 `VALIDATION_FAILED`。
- 未处理 Exception：记录服务端日志，对外转换为 `INTERNAL_ERROR`，不泄漏异常堆栈。

### 6.5 幂等基础约束

- 所有 POST/PATCH 在 OpenAPI 中要求 `Idempotency-Key`。
- Key 长度为 16 至 128 个字符。
- 同一工作空间、用户和 Key 的幂等有效期为 24 小时。
- 同 Key、同请求指纹返回首次响应。
- 同 Key、不同请求指纹返回 `IDEMPOTENCY_KEY_CONFLICT`。
- 当前仅实现 Header 校验依赖，数据库持久化将在数据层阶段实现。

### 6.6 健康检查

当前接口：`GET /api/v1/health`。

当前返回：

```json
{
  "request_id": "req_xxx",
  "data": {
    "status": "ok",
    "service": "ok",
    "database": "not_configured",
    "ai": "mock"
  }
}
```

这表示 FastAPI 服务可运行，但数据库尚未配置，AI 当前为 Mock 模式。

- OpenAPI 版本：3.1.0。
- 基础路径：`/api/v1`。
- P0 路径数量：26。
- POST/PATCH 写操作数量：16。
- 缺少 `Idempotency-Key` 的写操作：0。

注意：`openapi.yaml` 是目标 P0 契约，不代表其中所有接口都已经有路由实现。目前实际挂载的业务接口只有健康检查。
