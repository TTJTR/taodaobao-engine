# 淘到宝引擎 V1.1 互动 HTML 演示集成说明

## 1. 产品位置

互动 HTML 不是独立工具，也不接收任意自由文本。它是可信方案的正式演示产物：

```text
快速方案 / Deep Research
→ 后端 Trust Gate
→ released Claim + granted Evidence
→ PresentationInputSnapshot
→ AI 互动 HTML 编排
→ 事实绑定审计 + 静态安全审计
→ HtmlArtifact
→ 业务端沙箱预览 / 当前设备浏览器全屏打开 / HTML 下载
```

互动模式用于比赛演示和客户现场讲解，强调章节导航、滚动叙事、悬停和点击展开。本版本只验收
HTML，不把 PPTX/PDF 生成及视觉回归纳入交付范围。

## 2. 增量接口

`POST /api/v1/solution-runs/{run_id}/interactive-presentations`

`GET /api/v1/presentations/{presentation_id}/artifact?download=false`

请求和响应定义在 `docs/openapi-presentation-v1.1-incremental.yaml`。既有冻结 `openapi.yaml` 与
`app/contracts/ai.py` 五个方法签名不变；互动生成通过演示 Provider 适配层实现，不增加第六个
`AIEngine` 方法。

创建请求中的 `style_profile_id` 为可选字段。省略时，后端根据 `visual_direction` 创建可审计的系统
风格快照，因此用户可以从已通过 Trust Gate 的方案直接生成 HTML，不需要先上传 PPTX。传入真实
风格画像时仍沿用原有确认和版本校验。

## 3. 可信与安全边界

- 只有 `RELEASE` 或 `DOWNGRADE` 方案可创建任务。
- 每条 released Claim 在 HTML 中必须恰好出现一次，文本逐字一致。
- Evidence 如展示，ID 与 quote 必须来自同一输入快照并逐字一致。
- 未绑定可见文字只允许固定系统标签，模型不能自行补充客户结论或量化效果。
- 禁止外部资源、网络请求、表单、浏览器存储、Cookie、父页面访问、跳转和动态文字注入。
- 浏览器以 `sandbox="allow-scripts"` 运行产物，不授予 `allow-same-origin`。
- 独立 HTML 地址同时返回响应级 CSP sandbox；只能访问状态为 `ready` 的已审计产物。
- 任何事实或安全违规都会使 Worker 失败，不写入可用 `HtmlArtifact`。

## 4. 运行配置

```env
APP_INTERACTIVE_HTML_MODE=live
APP_INTERACTIVE_HTML_BASE_URL=https://api.deepseek.com
APP_INTERACTIVE_HTML_API_KEY=仅写部署环境
APP_INTERACTIVE_HTML_MODEL=deepseek-chat
APP_INTERACTIVE_HTML_TIMEOUT_SECONDS=180
```

正式运行只允许 `live` 模式；模型不可用时任务明确失败，不生成 Mock 功能结果。产物通过事实与安全
审计后进入 `ready`，密钥不得进入 Git、浏览器或接口响应。

## 5. 当前限制

- 静态审计通过不等于浏览器视觉质量测量；`render_report.visual_check` 会明确记录检查范围。
- 正式访问时由用户本机 Chrome/Edge 渲染；服务器只负责生成、审计、保存和分发 HTML。
- 浏览器视觉自动化可在开发机或 CI 配置 `PRESENTATION_TEST_BROWSER`，不作为生产服务器常驻服务。
- 互动稿的业务文字被锁定；需要改事实时应返回方案/Trust Gate 重新生成，而不是在演示层修改。
- 当前只支持 HTML 打开与下载。
