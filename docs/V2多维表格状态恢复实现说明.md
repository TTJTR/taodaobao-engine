# V2 多维表格状态恢复实现说明

## 目的

前端刷新后应恢复当前工作区已经创建的真实飞书多维表格目标，展示“已连接”和“打开多维表格”，但不能因为刷新页面而重复追加业务记录。

## 增量接口

- `GET /api/v1/feishu/bitable/sync-status`
- 只读取服务端持久化的 `app_token`、`table_id`、真实 URL、最近持久化时间及最近一次写入条数。
- 不调用飞书写接口，不新增记录，不修改客户画像或可信资产。
- 未建立同步目标时返回 `configured: false`。

真实写入仍由现有的 `POST /api/v1/feishu/bitable/sync-daily` 完成，并要求 `Idempotency-Key`。

## 前端行为

工作区加载时并行读取同步状态。状态接口失败不影响核心页面加载；成功时恢复真实多维表格链接，用户可以打开或主动再次同步。
