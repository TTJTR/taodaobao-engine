## 本次排障记录

Docker Desktop 最初因 Windows 运行时 Unix Socket 残留无法启动，涉及：

- `%LOCALAPPDATA%\Docker\run\dockerInference`
- `%LOCALAPPDATA%\Docker\run\sailor-ingest.sock`
- `%LOCALAPPDATA%\docker-secrets-engine\engine.sock`

处理方式为升级 Docker Desktop、重启 Windows，并在 Docker 完全退出后把对应运行时目录改名备份，再一次性启动。没有执行 Factory Reset，没有删除 Docker Volume、镜像或项目数据。详细安全步骤见[本地部署故障排查](本地部署故障排查.md)。

首次构建期间遇到一次 Docker Hub 鉴权超时和一次 Debian 软件源 `502 Bad Gateway`。确认 Docker 正在使用本机系统代理后，单独拉取基础镜像并重试，构建成功。未使用来源不明的第三方镜像。
