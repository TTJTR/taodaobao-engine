# 真实性审计与当前能力边界（2026-08-15）

## 审计结论

本版本已将生产依赖统一为真实 Provider 路径。未配置服务不再回退 Mock，前端不再初始化演示客户、资料、经验、能力、会话或经营指标，也不再用固定方案文案补齐后端空结果。

## 已确认可用

- V0.5/V1 资料、画像、经验、能力、快速方案的真实 API 结构；
- Deep Research、专家协作、可信编排和任务状态；
- V2 情报治理、画像 Proposal、招标响应矩阵、方案演练；
- 互动 HTML 真实模型适配与事实/安全审计；
- 多次邀请码及有效期限制；
- 内置虚构文档的真实索引验收脚本。
- 阿里云公开搜索主链路，以及默认关闭的 Open Enrich 可选补充链路；Open Enrich 不能绕过 RawArtifact、引文校验或人工画像审批。

## 需要部署环境才能验收

- 真实 PostgreSQL/pgvector 的 Alembic Head 与索引命中；
- 百炼 Chat 与 Embedding 网络调用；
- 飞书 OAuth、资料同步、事件回调与真实建群；
- DeepSeek 互动 HTML 生成；
- Open Enrich 自动公网情报补充（可选，需要 Sidecar 与上游凭据；未配置不影响阿里云默认搜索和 V2 核心验收）。

缺少上述依赖时，验收结果必须写为 `skipped` 或 `failed`，不得用替身结果声明通过。

## 历史文档说明

`docs/V2测试验收结果.md` 与 `evals/V2合并与发布验收报告_20260814.md` 记录的是当时的历史测试环境，其中包含 Mock 验收描述，只能作为历史开发证据，不能代表本版本生产能力。当前验收以本文件、`V2.0最终产品与真实运行PRD.md` 和最新测试报告为准。

`fixtures/builtin_documents/index_cases.json` 中全部内容是虚构验收资料。它们用于观察索引标题、匹配理由与 `source_snapshot`，不代表神州数码真实案例或能力，也不得用于正式客户输出。
