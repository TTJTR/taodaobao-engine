# 淘到宝引擎 Local First 部署说明

## 1. 适用范围

本部署形态面向 Windows 10/11 普通电脑。Docker Compose 启动前端入口、FastAPI、
PostgreSQL + pgvector、Redis 和 Durable Worker。飞书、公开情报、互动 HTML 与外部展示
解析均为可选能力；关闭或未配置时显示 `disabled` / `not_configured`，不返回 Mock 成功结果。

根目录 `openapi.yaml` 与 `app/contracts/ai.py` 未改动。本地登录是
`docs/openapi-local-deployment-incremental.yaml` 中的兼容增量。

## 2. 从空电脑部署

1. 安装 Git、Docker Desktop（选择 Linux containers）和 PowerShell 7；重启电脑。
2. 在 Docker Desktop 中等待 Engine 显示 Running。
3. 克隆并切换本地产品分支：

   ```powershell
   git clone https://github.com/wxh042/xianjintuan-engine.git xianjintuan-engine-local
   Set-Location .\xianjintuan-engine-local
   git switch feat/local-deployment
   ```

4. 一条命令启动：

   ```powershell
   .\scripts\start-local.ps1
   ```

   首次运行会从 `.env.example` 创建 `.env`，生成数据库密码、会话密钥、Fernet
   密钥和本地管理员临时密码，并在终端显示一次密码。之后不会覆盖 `.env`。

5. 浏览器打开 `http://127.0.0.1:3000`，使用终端显示的本地管理员登录。

默认地址：

- 前端：`http://127.0.0.1:3000`
- API：`http://127.0.0.1:8000/api/v1`
- API 文档：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/api/v1/health`

## 3. 日常命令

```powershell
.\scripts\start-local.ps1 -NoBuild
.\scripts\status-local.ps1
.\scripts\logs-local.ps1 -Service app -Follow
.\scripts\logs-local.ps1 -Service worker -Tail 300
.\scripts\stop-local.ps1
```

`stop-local.ps1` 不删除 Volume。不要使用 `docker compose down -v`，除非已经备份并明确要清空数据。

## 4. 配置规则

修改 `.env` 后，服务端环境变量需要执行 `stop-local.ps1` 后重新启动。后台“模型与服务配置”
保存的是工作区级 Chat / HTML / 搜索路由，真实连通性测试成功后立即生效，不需要重启；API Key
使用 `APP_SECRET_ENCRYPTION_KEY` 加密落库，接口和页面只返回掩码。

关键配置：

| 配置 | 作用 |
|---|---|
| `HOST` | `127.0.0.1` 仅本机；`0.0.0.0` 主动允许局域网 |
| `FRONTEND_PORT` / `BACKEND_PORT` | 宿主机前端、API 端口 |
| `PUBLIC_BASE_URL` | 用户实际访问的前端根地址；局域网模式填写真实局域网 IP |
| `APP_CORS_ORIGINS` | 逗号分隔的允许前端来源，不支持任意 `*` 默认值 |
| `AI_PROVIDER` | Provider 说明标签；运行协议统一为 OpenAI Schema |
| `AI_API_KEY` / `AI_BASE_URL` / `CHAT_MODEL` | Chat 模型配置 |
| `EMBEDDING_API_KEY` / `EMBEDDING_BASE_URL` / `EMBEDDING_MODEL` | 独立 Embedding 配置；空 Key 时回用 `AI_API_KEY` |
| `EMBEDDING_DIMENSION` | pgvector 维度；修改后必须重建全部向量索引 |
| `APP_DATABASE_URL` / `APP_REDIS_URL` | 宿主机直跑地址；Compose 内自动使用 `db` / `redis` |
| `APP_FILE_STORAGE_ROOT` | 本地上传根目录；Compose 固定映射到持久化文件卷 |
| `APP_LOG_LEVEL` | `DEBUG`、`INFO`、`WARNING`、`ERROR`、`CRITICAL` |
| `AUTH_MODE` | `local`、`feishu` 或 `both` |
| `ENABLE_FEISHU` | 飞书 OAuth、文档、妙记、多维表格、专家群总开关 |
| `ENABLE_PUBLIC_INTELLIGENCE` | 自动公开情报总开关；手工真实来源仍遵循业务校验 |
| `ENABLE_DEMO_DATA` | 只声明是否允许演示资料；不会自动伪造业务数据 |

兼容规则：旧版 `DASHSCOPE_API_KEY` / `BAILIAN_BASE_URL` 仍可使用，但新的通用变量优先。
Chat 与 Embedding 分别调用 `/chat/completions` 和 `/embeddings`。

## 5. 局域网访问

在 `.env` 中设置：

```dotenv
HOST=0.0.0.0
PUBLIC_BASE_URL=http://192.168.1.20:3000
APP_PUBLIC_BASE_URL=http://192.168.1.20:3000
APP_FRONTEND_REDIRECT_URL=http://192.168.1.20:3000/
APP_CORS_ORIGINS=http://192.168.1.20:3000
```

将 `192.168.1.20` 替换为本机实际局域网 IPv4，并只在受信任网络中为前端、API 端口创建
Windows 防火墙入站规则。`HOST=0.0.0.0` 不能作为浏览器地址。

## 6. 数据持久化与备份

命名卷：

- `taodaobao-local_postgres_data`：数据库、任务、画像、资产、方案和快照；
- `taodaobao-local_redis_data`：Redis AOF；
- `taodaobao-local_local_files`：上传文件、导出物和集成状态。

备份：

```powershell
.\scripts\backup-local.ps1
```

输出到未跟踪的 `backups/`。应把备份复制到本机之外并限制访问权限。

恢复必须在测试机先演练。安全流程是：停止服务、保留旧卷、创建全新空卷，启动 `db`，使用
`psql` 导入 SQL，再将文件归档解压到新的 `local_files` 卷，最后启动全部服务并运行健康检查。
禁止直接把 SQL 覆盖导入含业务数据的数据库；如需清空旧卷，必须再次确认备份可读后手工执行。

## 7. 外部能力降级

- AI Key 未配置：登录、资料查看和数据库管理仍可用；AI/Embedding 操作明确返回 503。
- 飞书关闭：本地登录与粘贴文本、本地招标文件不受影响；飞书入口显示不可用。
- 公开情报关闭：自动搜索和 Open Enrich 不可用；不会生成假搜索结果。
- 互动 HTML 未配置：研究与方案结果保留，HTML 生成失败并显示 Provider 未配置。
- Worker 异常：已提交任务保留在 PostgreSQL；Worker 恢复后按租约继续处理。

## 8. 自动迁移

`app` 容器入口在启动 API 前执行 `alembic upgrade head`。迁移失败时容器不会继续提供业务服务，
避免在旧 Schema 上伪装健康。Worker 等待 API 健康后才启动。

## 9. 可选示例资料

设置 `ENABLE_DEMO_DATA=true` 与 `APP_ENABLE_DEMO_DATA=true`，配置真实 Chat/Embedding 后重启，运行：

```powershell
.\scripts\import-example.ps1
```

两份资料明确标记为虚构并写入 `is_demo=true`，但它们与用户粘贴资料使用同一个 API、数据库
结构、AI 提取和人工审核流程。缺少 AI Key 时导入明确失败，不产生写死的经验或能力结果。
