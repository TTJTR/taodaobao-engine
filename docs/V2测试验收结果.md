## 5. 安全与可信测试

- localhost、私网、链路本地和元数据地址会被公开来源 URL 校验拒绝；
- Office ZIP 限制条目数与解压后大小，PDF 限制页数，上传原始文件限制 5 MiB；
- 情报与内部经验/能力分开存储，不进入资产在线召回；
- 画像提案未经员工确认不会写入画像；确认后仍把长期画像置为待确认；
- 响应矩阵拒绝跨工作区、未校验、来源过期、来源版本变化或 Embedding 未完成的资产；
- `missing_evidence` 响应项不能审核为可承诺；
- 演练会识别绝对承诺、未说明证据和未暴露知识缺口；
- 所有新增业务查询按 `workspace_id` 隔离，POST/PATCH 要求 `Idempotency-Key`；
- 服务连接接口不返回 API Key 或飞书 Secret。
