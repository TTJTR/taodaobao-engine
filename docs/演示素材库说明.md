# 演示素材库说明

## 目标

素材库是模板运行时的受控输入，不是随意堆放图片的目录。每个文件必须有来源、固定上游版本、许可证、SHA-256、用途和生产准入状态，Renderer 只能消费 `runtime_eligible=true` 的条目。

## 目录

```text
app/assets/presentation/
  manifest.json                 # 唯一资产清单
  brand/digitalchina/           # 官方品牌素材，当前等待确认
  templates/presenton/          # 精选 Template v2 JSON
  thumbnails/                   # 模板人工评审图
  decorations/                  # 无业务语义的矢量装饰
  fonts/                        # 带独立字体许可的字体文件
  licenses/                     # 第三方许可与归属
  gallery/index.html            # 固定 16:9 人工审阅页
```

## 准入规则

1. 模板、缩略图和装饰来自 `presenton/presenton@b940f7b4a51d473af830d96d441276af3540dae6`。
2. 示例业务照片不进入素材库，避免把上游示例内容误作客户素材。
3. SVG 禁止 `script`、`foreignObject`、事件属性、外部 URL 和 JavaScript URL。
4. 哈希、路径、MIME、许可文件或来源字段缺失时校验失败。
5. 品牌素材必须来自官方渠道并人工确认；未确认资产不能进入运行时。
6. 重复哈希视为资产治理问题，需合并或显式解释，当前清单不保留重复文件。

## 中文字体基线

R1 使用思源黑体（Noto Sans SC Variable Font）测量中文容量。字体固定到
`google/fonts@038b637da7b3fd956a4ed93ffc607c3d5e4ce172`，文件 SHA-256 为
`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`，许可为 OFL-1.1。
该字体支持 30,890 个 Unicode 字符及 100-900 可变字重。容量测试必须引用清单中的该文件，不能静默回退到系统同名字体。

## 当前模板集

- `Modern`：克制、留白充分，适合咨询方案正文和证据页。
- `Executive`：强对比大标题和深色视觉，适合封面、章节页和关键结论。
- `Momentum`：更强调节奏与动势，适合流程、路线图和行动计划。

三套模板现在作为“候选模板源”纳入。后续必须经过语义槽位裁剪和 Golden Screenshot 人工评审，才允许由运行时直接填充事实。素材入库不等于模板已完成业务适配。

## 品牌素材

采集时神州数码官网返回 HTTP 521，未取得官方 Logo 原件。素材库不会用搜索引擎图片或 AI 生成近似 Logo。需由组长或品牌联系人提供官方 SVG/PNG 与 VI 颜色规范，随后补录来源、哈希并将状态从 `pending_brand_confirmation` 改为 `confirmed`。
